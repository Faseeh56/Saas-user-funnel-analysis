# 🚀 SaaS Funnel Analytics Dashboard

An interactive SaaS analytics dashboard built using **Python**, **Streamlit**, **Plotly**, and **NLP techniques** to analyze user behavior, conversion funnels, churn patterns, customer sentiment, and cohort retention.

This project simulates a real-world SaaS product analytics environment using a synthetic but business-realistic dataset.

---

# 📌 Project Overview

This dashboard helps analyze how users move through a SaaS product funnel:

```text
Landing → Sign-up → Onboarding → First Feature Use → Upgrade
```

The project focuses on:

* Funnel conversion analysis
* Churn analysis
* User engagement metrics
* Cohort retention analysis
* NLP-based sentiment analysis
* Interactive business intelligence dashboarding
